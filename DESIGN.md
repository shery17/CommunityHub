# CommunityHub design

## Shared layout

- Set the wordmark and primary actions in berry. Use stone neutrals for text, dividers and secondary controls.
- Align navigation, content and footer to a common page width. Use a quiet footer with real navigation and attribution links.
- Pair the homepage introduction with a local market photograph.
- Use simple single-column account and organiser forms. Separate sections with spacing and dividers.
- On event detail pages, put the title and venue above the photo, and place registration beside the description on wide screens.

## Browse Events

- Use a white canvas, dark headings, quieter secondary text, and CommunityHub berry for primary actions and focus. Use the system sans-serif stack.
- Give the cover photo a consistent landscape crop and rounded corners. Keep the title, schedule, venue, distance when available, and price directly below it. The entire listing links to the event. Listings without photos use the same text hierarchy with a subtle divider.
- On desktop, group keyword, location and date in one search bar. Place lookup results open below Location. The browser calendar opens from Event date. Keep advanced filters in a separate disclosure.
- On mobile, open a search panel from one button. Apply edits with Show events, or close the panel to discard them. Display active filters as removable chips on the results page.
- Keep registration warnings visible when relevant. Put descriptions and the full schedule on the event detail page.

The Airbnb screenshots guide layout and interaction. CommunityHub uses its own colours, wording and event photos.
