# CommunityHub

**Bringing Local Communities Together**

CommunityHub is a full-stack web application for discovering and organising local community events.

Users will be able to:

- Create and post local events
- Discover events in their community
- Register/RSVP for events

## Tech Stack

### Frontend

- React
- Vite
- JavaScript

### Backend

- Node.js
- Express.js

### Planned

- Database
- User authentication
- Event registration/RSVPs
